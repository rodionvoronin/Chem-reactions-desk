# Chem Reactions Desk

Виртуальная лаборатория качественного анализа для школьников. Ученик смешивает
реагенты в пробирках, видит осадки, газы и окраску растворов — и учится выводить
состав вещества из наблюдаемых признаков, а не подбирать реагенты наугад.

**Открыть:** https://rodionvoronin.github.io/Chem-reactions-desk/

В основе — таблица из 838 правил и 751 уникального уравнения, охватывающая
132 реагента: катионы и анионы всех аналитических групп, окислительно-восстановительные
реакции, термическое разложение, окрашивание пламени.

## Пять режимов

**Песочница.** Свободный стол: любое число пробирок и горелок, все реагенты,
водный и сухой режим. Под столом сразу показывается уравнение прошедшей реакции.
Ограничений и проверки нет — это режим для первого знакомства и для опытов
«а что будет, если».

**Режим заданий.** 37 задач по десяти темам: определить неизвестное вещество,
добиться заданного признака, различить пару, определить металл по окраске пламени,
работать в сухом режиме, провести цепочку превращений. Вместо жизней и таймера —
**бюджет реактивов**: у задачи есть запас приливаний, подсказка стоит бюджета.
Это не игровая условность, а настоящее ограничение аналитика: реактивы стоят
денег, образец конечен, поэтому в лаборатории сначала составляют схему анализа,
а потом идут к штативу.

После ответа — разбор: фактический ход ученика ставится рядом с оптимальным,
и только тогда открываются уравнения.

**Дела.** Три расследования из трёх-четырёх задач: сорванные этикетки на складе,
проба воды ниже завода, что осталось в печи. Каждый шаг открывает улику,
а финальный вопрос решается только по всем уликам сразу.

**Тренажёр ЕГЭ.** Задания 6, 7, 8, 9, 29 и 30 в формате экзамена. Условия не
хранятся списком, а собираются из той же таблицы реакций при каждом показе,
поэтому не кончаются и не заучиваются. Для 30 разбор показывает молекулярное,
полное и сокращённое ионные уравнения, для 29 — электронный баланс
с окислителем и восстановителем.

**Лабораторный журнал.** Каждое впервые увиденное уравнение попадает в коллекцию
и раскладывается по 16 семействам — осадки гидроксидов, газы, амфотерность,
ОВР, разложение при нагревании. У семейства видно «открыто 7 из 12» и ступени;
рядом — что попробовать дальше. Он же работает справочником при подготовке.

## Ключевое решение: уравнения — единственный источник правды

Реакция описывается одной строкой:

```ts
{
  inputs: ['FeCl3', 'NaOH'],
  effects: { precipitate: { color: '#BF360C' } },
  description: 'FeCl₃ + 3NaOH → Fe(OH)₃↓ + 3NaCl',
}
```

Всё остальное **вычисляется** из этой строки, а не дублируется рядом с ней:

| Что нужно | Откуда берётся |
|---|---|
| Продукты реакции | разбор уравнения (`src/chem/formula.ts`) |
| Ионные уравнения, полное и сокращённое | ионный состав + растворимость (`src/chem/ionic.ts`) |
| Степени окисления, окислитель и восстановитель | расчёт по правилам (`src/chem/oxidation.ts`) |
| Семейства журнала | признаки, продукты и степени окисления (`src/game/families.ts`) |
| Эталонные признаки заданий | движок реакций, а не текст условия |
| Цепочки превращений | граф «вещество + реагент → вещество» (`src/ege/graph.ts`) |

Отсюда два следствия. Во-первых, задания и семейства не ломаются при правке
химии — они пересобираются. Во-вторых, базу можно проверить целиком: сплошная
сверка баланса атомов и зарядов нашла в ней 7 химических ошибок, включая
уравнение, где был неверен сам продукт.

## Цепочки на столе

Задание 9 ЕГЭ на бумаге спрашивает, чем перевести одно вещество в другое.
На столе это делают руками: осадок **выделяют** и продолжают работать уже
с ним, как в настоящем анализе.

```
CuSO₄ --NaOH--> Cu(OH)₂↓ --выделить--> Cu(OH)₂ --HCl--> CuCl₂
```

Выделение доступно, только когда кандидат ровно один: иначе ученик и движок
выбрали бы разное, и разбор разошёлся бы с фактическим ходом. У пробирки
с загаданным образцом выделение закрыто — оно назвало бы вещество вслух.

## Что видит ученик после решения

Вместо одной оценки — **гистограмма экономности**: шкала приливаний с точками
всех его решений, отметками оптимума и бюджета. Три звезды отвечают на вопрос
«идеально или нет», и ответ почти всегда «нет». Гистограмма отвечает на другой
вопрос — насколько ход стал короче, — и на него хороший ответ есть почти всегда.

Если преподаватель выдал классу код, на шкале появляются столбики класса
и строка «короче, чем у 8 учеников из 12». Без такого кода приложение
сравнивает ученика только с ним самим: чужих результатов оно не выдумывает.

## Проверки

```bash
npm run check
```

Шесть независимых проверок, любая из них может уронить сборку:

- `check:chem` — все 733 уравнения сходятся по атомам и зарядам; 722 сокращённых
  ионных уравнения строятся и сходятся; 92 пометки «окислитель/восстановитель»
  совпадают с расчётом по степеням окисления;
- `check:families` — 16 семейств разбивают базу без потерь и пересечений;
- `check:cases` — сюжеты дел не расходятся с таблицей: если реакция из рассказа
  не идёт или не даёт обещанного осадка и газа, дело не соберётся;
- `check:ege` — генератор собирает по 40 заданий каждого номера, и у каждого
  перебором проверяется **ровно один верный ответ**;
- `check:tasks` — каждая задача банка решается своим эталонным ходом (включая
  шаги выделения продукта), дистракторы от ответа отличимы, а целевого вещества
  цепочки нет в палитре;
- `check:logic` — засчитывание ответов, звёзды, достаточность доказательства,
  формулировки гистограммы и код результата.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
```

## Структура

```
src/
  reactions.ts        база реакций: реагенты, правила, движок сопоставления
  App.tsx             роутер экранов
  Lab.tsx             лабораторный стол: песочница и решение задачи
  useViewport.ts      признак узкого экрана — от него зависит мобильная раскладка
  chem/               разбор формул, вещества, ионные уравнения, степени окисления
  ege/                граф реакций и генератор заданий ЕГЭ
  game/               банк задач, дела, семейства, проверка, прогресс, телеметрия
  components/         пробирка, горелка, палитры, нижняя шторка, панели заданий
  screens/            меню, карта заданий, дела, журнал, тренажёр ЕГЭ, преподаватель
scripts/              шесть проверок базы и заданий
docs/pilot.md         протокол пилота: как провести занятие и снять метрики
```

## Телефон

Ниже 860 пикселей палитры уезжают в нижнюю шторку с вкладками, условие задачи
и реагенты — тоже, а счётчик реактивов выносится в верхнюю полосу. Шторка
закрывается после каждого действия: открытая, она закрывала бы собой пробирку
и панель результата, то есть ровно то, ради чего реагент лили.

Десктопная раскладка при этом не изменилась — это проверено побайтным
сравнением разметки с версией до правок.

## Развёртывание

Пуш в `main` запускает GitHub Actions: сборка и публикация на GitHub Pages
(`.github/workflows/deploy.yml`). Пути в сборке относительные, поэтому проект
работает и из подпапки, и с локального сервера.

## Данные ученика

Прогресс, журнал и лог событий хранятся в `localStorage` — аккаунтов и сервера нет.
Преподаватель получает результат кодом: ученик копирует строку с итогами,
преподаватель вставляет коды на своём экране и видит сводную таблицу
с избыточностью хода, долей решённых с первой попытки и работой вне заданий.
Таблица выгружается в CSV, а распределение по классу возвращается ученикам
отдельным кодом — без имён.

Если компьютеры в классе общие, перед следующим учеником прогресс стирают:
«Экран преподавателя» → «Начать с чистого листа».

Подробности о метриках, ходе занятия и границах выводов — в [docs/pilot.md](docs/pilot.md).
